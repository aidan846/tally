Usage

Ask. Calculate. Keep going.

Tally is a flexible scratchpad for arithmetic, conversions, dates, geometry, live data, and the small decisions that come up every day.

01

Write calculations naturally

Use everyday language alongside symbols, functions, parentheses, constants, percentages, arrays, and scientific notation. Tally follows the question, not a rigid formula.

Tally
sum of 72 and 54 minus 3294.00
20% off 8568.00
sqrt4 + sin(pi / 2)3.00
1:10[1, 2, 3, …]

Ask for averages, medians, midpoints, random numbers, rounding, signs, or scientific notation. When a command needs more values, a trailing space shows the next expected inputs without changing your text.

Make it yours

Choose light, dark, or automatic appearance and set precision from zero to five decimal places. Preferences stay on your device. Press Enter for the next row, C C C to clear, X X to delete the current row, or Ctrl C to copy the current line.
